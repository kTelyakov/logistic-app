# Proposal

## Why

Синхронизация и хранение готовы, но экрана нет. Нужен экран диспетчера, который показывает состояние сервера: очереди по пунктам, ленту решений с обратным отсчётом, статус связи, время в часовом поясе площадки. Это часть 2 задания (пункты 2, 3, 5) и требования 1, 6, 7, 8. Команды (отмена, режим пункта) и схема на WebGL добавляются следующими changes и опираются на эту основу.

## What Changes

- Модуль `session`: `/api/me`, роль, площадка, форматирование времени в поясе площадки (не браузера).
- Модуль `points`: хранилище пунктов, панель очередей.
- Модуль `decisions`: хранилище решений (за последний час по серверному времени), лента (новые сверху), обратный отсчёт до `execute_at` по серверному времени.
- Модуль `sync`: индикатор связи (подключено, переподключение, данные устарели), серверные часы для интерфейса.
- Корневой контейнер `src/app/AppContainer.vue`: загрузка сессии, запуск синхронизации, применение пакетов к хранилищам, раскладка экрана, контракт для тестов (`window.__dispatch`, `data-testid`).
- Адрес сервера: `?api=<url>` (стенды и e2e) или тот же origin; в разработке Vite проксирует `/api`, `/ws`, `/debug` на заглушку.
- Стили без внешних ресурсов: шрифты и иконки только системные или из сборки.
- e2e-фикстуры переключаются на настоящий экран; эталонный экран остаётся для проверки основы.

## Capabilities

### New Capabilities
- `dispatcher-screen`: что видит диспетчер: очереди, лента решений, связь, время площадки; не считает показатели сам; безопасный вывод текста; работа без внешних ресурсов.

## Impact

- Новые модули `session`, `points`, `decisions`, дополнения `sync` и `vehicles`, каталог `src/app/`.
- `vite.config.ts` (прокси), `playwright.config.ts` (запуск экрана), `tests/e2e/fixtures`.

## Non-Goals

- Кнопка «Отменить», переключатель режима, обработка 409 и 403 (`decisions-and-commands`).
- Схема площадки (`site-renderer-webgl`).
- Правила `make check` (`code-rules-check`).
