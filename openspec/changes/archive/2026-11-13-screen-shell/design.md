# Design

## Context

Транспорт отдаёт пакеты в `BatchTarget`; правила модулей и контейнеров — в AGENTS.md. См. proposal.md.

## Goals / Non-Goals

**Goals:** экран показывает состояние сервера и проходит сверку с `/debug/state`; время и отсчёты только серверные.

**Non-Goals:** команды, схема, правила линтера.

## Decisions

- **Корневой контейнер `src/app/AppContainer.vue`:** единственное место, которое знает все модули. Он реализует `BatchTarget` (пакет, хранилища), запускает синхронизацию и раскладывает контейнеры модулей. Контейнеры модулей не знают друг друга. Это снимает prop drilling: каждый блок берёт данные из своих хранилищ.
- **Контейнер готовит модель представления, компонент только показывает:** время форматируется в контейнере по поясу площадки, отсчёт считается в контейнере по серверному времени; компоненты получают готовые строки и числа через props и сообщают о действиях через emit.
- **Серверное время для интерфейса:** composable `useServerNow` обновляет реактивное значение раз в 500 мс из `connectionStore.serverNow()`. Часы браузера напрямую не используются.
- **Статус связи:** «данные устарели» считается в основном потоке как `idleMs` воркера плюс время с получения статуса: так «устарели» видно и при зависшем воркере. Порог 15 секунд (три heartbeat).
- **Решения за час:** хранилище удаляет решения старше часа по серверному времени раз в минуту и при каждом применении пакета с заменой. Это же окно у заглушки (`recentDecisions`), поэтому сверка совпадает.
- **Адрес сервера:** `?api=` в URL, иначе тот же origin. В разработке Vite проксирует `/api`, `/ws`, `/debug` на заглушку (`MOCK_URL`, по умолчанию `127.0.0.1:8787`). Параметр нужен стендам и e2e, где у каждого теста своя заглушка.
- **Контракт для тестов через `window.__dispatch`:** хук читает `appliedSeq` и вид машин; машины не в DOM. Остальное в DOM через `data-*`, как это видит диспетчер.
- **Стили:** обычный CSS с переменными, системные шрифты; внешних ресурсов нет. Тёмная палитра для работы в диспетчерской.
- **e2e на настоящем экране:** Playwright поднимает `vite` на 5199; эталонный экран остаётся для foundation-тестов.

## Risks / Trade-offs

- [Перерисовка лент на каждый пакет] → пакеты раз в 50 мс, сущности дедуплицированы, списки малы (очереди до 20, решения за час).
- [Хук `window.__dispatch` в боевой сборке] → безвреден (только чтение), документирован как тестовый шов.
