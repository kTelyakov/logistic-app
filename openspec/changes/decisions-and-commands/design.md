# Design

## Context

Транспорт и экран готовы; заглушка реализует идемпотентность, 409 и 403, а при `FAULTS=slow` задерживает HTTP на 3 секунды и часть команд выполняет до задержки. См. proposal.md.

## Goals / Non-Goals

**Goals:** одно выполнение на сервере при любых повторах; экран всегда показывает подтверждённое сервером.

**Non-Goals:** подтверждения, отмена отправленной команды.

## Decisions

- **Ключ один на намерение:** `createCommandKey()` вызывается в момент нажатия, затем передаётся во все попытки. Используем `crypto.randomUUID()` (в защищённом контексте), иначе генерация из `getRandomValues`.
- **Повтор с растущим таймаутом (2 с, 5 с, 10 с):** при задержке сервера 3 с первая попытка всегда оборвётся, вторая дождётся ответа. Постоянный короткий таймаут повторял бы запросы бесконечно. Повторяем таймаут, сетевую ошибку и 5xx; 200, 400, 403, 404 и 409 не повторяем.
- **Без оптимистичных обновлений:** до ответа экран показывает прежнее; кнопка блокируется и показывает ожидание. Ответ применяется через `applyServerDecisionMutator`/`applyServerPointMutator` (версия не старее). Опоздавшее сообщение потока со старой версией не затирает ответ.
- **Состояние команд локально в composable контейнера:** «в пути» и ошибки по сущности нужны только контейнеру; в Pinia остаются сущности. Сообщения диспетчеру идут в общий стек `shared/notices` (Pinia): они общие для модулей и живут недолго.
- **Кнопки только у диспетчера:** `sessionStore.mayCommand` решает, рендерить ли действие; наблюдатель получает 403 только при обходе интерфейса.
- **Слот действий в ленте и свойство `canCommand` в панели очередей:** презентационные компоненты не знают о запросах, действия идут через `emit`.
- **Ответ 409 с `pending`:** значит устарела версия; сообщение предлагает проверить актуальное состояние, сущность из ответа уже показана.

## Risks / Trade-offs

- [Неизвестный исход после трёх таймаутов] → сообщение, возврат управления, актуальное состояние придёт из потока; повторное нажатие создаёт новое намерение и новый ключ, а `If-Match` защитит от двойного эффекта.
- [Кнопка нажата на решении, которое только что исполнилось] → 409 с понятным сообщением.
